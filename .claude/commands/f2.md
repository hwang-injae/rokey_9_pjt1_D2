`docs/prompts/F2_민범진_프롬프트.md` 파일을 읽고, 그 내용이 사용자의 첫 메시지로 온 것처럼 그대로 수행한다.

- 파일 안의 `______`(이름·수준·GitHub ID·내 PC)는 먼저 사용자에게 한 번에 물어서 채운 뒤 시작한다. 사용자 인자 $ARGUMENTS 가 있으면 그것을 "내 이름 / 수준"으로 쓴다.
- 프롬프트 §0 시작 순서대로 먼저 온보딩 상태를 확인한다(이미 마쳤으면 건너뜀). 그다음 규칙 0~10을 그대로 지킨다: 관련 파일(AGENTS.md, docs/01~03, 내 프롬프트)을 실제로 읽고 **읽은 파일 목록 → 역할·산출물 → 인터페이스 표 → STEP 계획**을 먼저 내고, 승인 전에 구현하지 않는다.
- 이미 진행 중이던 작업이 있으면(`git branch`, `git log --oneline -5`, `docs/test_logs/` 확인) 어디까지 했는지 요약하고 다음 STEP을 제안한다.
- 부록 A(AGENTS.md 전문)는 저장소의 AGENTS.md와 같으므로 다시 읽지 않아도 된다.
