## 역할 재조정 (회의 후 PM 정리)
- PM은 **황인재**(초안에서 민범진으로 잘못 가정했던 PM성 작업을 되돌림): `cobot_msgs` 정본 관리, `prewash_bringup` 런치, `prewash.yaml` 골격, 노션 노드 구조·인터페이스 업로드(NOTE-01), 제출 → 황인재.
- 민범진: `f2_node` + `flow_node` + `mock_f1_f3` + 통합 실행 주도(L2 INT-12a, L3·L4).
- `place`는 항상 **놓기(release)까지 포함**한다. 스펀지 홈에서는 쥔 채 순응 하강·탐색으로 안착시킨 뒤 놓는다(구 `seat` 흡수). 따라서 F3의 닦기는 "용기가 홈에 놓여 있고 그리퍼는 비어 있는 상태 → 툴 픽업"에서 시작한다.
- 박진용: 재료가 9/19 오전 도착 → 기구 제작(CELL-02)·V-12는 9/19 오전으로. 9/18 저녁은 V-03(힘제어 중 XY 이동), `cobot_common`의 힘 관련 함수(INF-02b), 안전 파라미터·위험요소 표(SAFE-01), 용기 치수 측정·홈 커팅 도면. 안착이 F1으로 간 대신 힘 함수 작성과 V-15·V-18 검증을 맡는다.
- 추가 검증 V-15~V-22를 일정표와 SDD §9.2에 추가(파지 폭 재파지, 파지력·미끄러짐, 컵 파지 방식, 툴 파지 안정성, 도달 범위, 여러 노드의 두산 API 동시 사용, 서비스 콜백 안 장시간 모션, 티칭 좌표 재현 오차).

## 영향
- 확정된 1·2·6은 IRD v2.0·SDD와 같다. **6-1(닦기 서비스 분리)은 `cobot_msgs` 변경이 필요**: `srv/F3Wipe.srv`·`F3Seat.srv` 삭제, `F3WipeBowl.srv`·`F3WipeCup.srv` 추가, `F1Place.srv` 응답에 `offset_mm` 추가(정본 `docs/interfaces/`), CMakeLists 갱신 → 민범진 PR.
- PM 발견: 초안의 호출 순서 `place → seat`은 모순(놓은 뒤에는 순응 하강·탐색을 할 수 없음). `seat`이 용기를 쥔 채 안착하고 끝에서 놓는 것으로 정정 제안 → DSN-03 확인.
- 3·4가 DSN-03에서 바뀌면 `F1Pick.srv`·`FlowState.msg`·`FlowEvent.msg`가 바뀔 수 있다 → 인터페이스 변경 이슈 → `cobot_msgs` 수정 PR. 그 전까지 F1의 `pick` 탐색 구현(F1-02)과 F4의 화면 필드 바인딩은 **초안 기준으로 진행하되 바뀔 수 있음**을 전제로 한다.
