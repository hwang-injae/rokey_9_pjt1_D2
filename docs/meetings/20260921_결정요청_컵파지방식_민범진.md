## 1. 🔴 컵에서 막힌 것 — 한 줄로

> **컵을 누르지 않으면서 "잡았는지"도 아는 방법이 없습니다.**

```
끝까지 닫으면  →  잡았는지 안다 ✅  ·  컵이 눌린다 🚨
덜 닫으면      →  안 눌린다 ✅       ·  잡았는지 모른다 🚨
```

**둘 중 하나는 버려야 합니다.** 그래서 결정을 요청드립니다.

## 2. 🔴 결정해 주실 것 — **컵이 눌리는 것을 감수할까요?**

### ✅ 감수한다면 → **결정 끝. 아무것도 안 바꿔도 됩니다**

끝까지 닫으면 폭으로 확실히 구분됩니다. 오늘 실측값입니다.

```
빈손   10.58 mm  (고무 핑거팁끼리 만나는 자리)
컵     54.90 mm  (눌렸어도 컵이 버티는 자리)
        ↓
     44 mm 차이 — 흔들림 0.20 mm 대비 220배
```

🔔 컵은 **10회 내내 54.90 · 흔들림 0.00 mm** 였습니다. 눌린 상태여도 **매번 같은 자리**에서 멈춥니다.
   오히려 그릇(0.30)보다 안정적입니다.

**다만 힘은 5 N 으로 유지해야 합니다** — 20 N 에서는 안전 스위치가 걸렸습니다(§3 ③).

### ❌ 감수 못 한다면 → **파지 방식을 바꿔야 합니다**

| 안 | 내용 | 비용 |
|---|---|---|
| **㉠** | 컵 **테두리(림)** 를 잡는다 — 그릇과 같은 방식 | F1 집기(한석형) 변경 · IRD 파지 방식 · 컵 자세 재티칭 |
| **㉡** | 더 **단단한 컵**으로 바꾼다 | 용기 조달 · 치수가 바뀌면 컵 좌표 재티칭 · 9/23 동결까지 빠듯 |

## 3. 왜 "덜 닫기" 와 "힘으로 확인" 은 안 되는가 (전부 실측)

### ① 힘 낮추기 — ❌ 최저값에서도 눌림

```
20 N  →  눌림 + 🚨 안전 스위치 작동 (그리퍼 수동 분리로 복구)
15 N  →  눈에 보이게 눌림
 5 N  →  그래도 눌림      ← RG2 로 쓸 수 있는 **최저**
2.5 N →  데이터시트 유효 범위(3~40 N) 밖
```

🔔 숫자로는 안 잡힙니다 — V-23 이 *"폭 변화 0.10 mm · 낙하 0 · **OK**"* 로 통과합니다.
**잡은 뒤의 변화만 재기 때문**이고, 닫히는 **동안** 이미 눌립니다. 육안으로만 보입니다.

### ② 폭 제한(78 mm 에서 멈추기) — ❌ 빈손과 구분 불가 + 힘 전환도 깨짐

**빈손으로 같은 명령을 돌려 확인했습니다.**

| | 읽힌 폭 |
|---|---|
| 컵 있음 | **77.90** |
| **빈손** | **77.80** |

→ 차이 **0.10 mm**. 폭 흔들림이 **0.20 mm** 라 **구분이 안 됩니다.**
→ 그런데 시험은 **"낙하 0 · 폭 변화 0.00 · 판정 OK"** 로 나옵니다. **아무것도 안 잡고 통과합니다.**

그리고 **힘 설정이 아예 안 먹습니다**:

```
 5 N 요청 → 20.0 N 유지
10 N 요청 →  5.0 N 유지  (3회 모두)
```

이유: 드라이버에서 힘 변경은 **"같은 폭으로 다시 잡기"** 입니다. 목표 폭에 이미 도달해 있으면
다시 잡을 것이 없어 아무 일도 일어나지 않습니다. → **털 때 HOLD 로 세게 쥐는 것도 안 됩니다.**

🚨 **실기에서 컵을 놓쳐도 "잡았다" 로 읽고, 빈 집게로 세제·닦기·적재를 끝까지 한 뒤
   "성공" 으로 기록합니다.** 시연에서 나면 아무도 못 알아챕니다.

### ③ 힘·신호로 확인 — ❌ 빈손과 같은 값이 나옴

집게에 **압력을 재는 센서가 없습니다.** 우리가 읽는 값은 드라이버가 **설정한 목표 힘**이 되돌아오는 것입니다.

| | 읽힌 힘 |
|---|---|
| 컵을 잡은 상태 | **5.0 N** |
| **빈손** | **5.0 N** |

"잡았다" 신호도 **빈손에서 뜹니다**(9/21 오전 probe ⑤ — 빈손으로 닫혀 있는데 35.0 N 이 읽혔습니다).
집게 입장에서는 **컵에 막힌 것과 반대쪽 고무에 막힌 것이 같습니다.**

> 🔔 강의 노션의 DO/DI 방식(`get_digital_inputs` → 물체 파지 = 3)도 같은 한계입니다.
>    그 방식이었다면 **빈손을 파지 성공으로 읽었을 것**입니다 — 우리가 폭으로 판정하는 근거가 됩니다.

세션 중에는 컵 상태를 계속 쓰느라 못 봤습니다. **이것부터 보고 결정하시는 것**을 권합니다.

## 5. 제 의견

**"감수한다"** 쪽이 현실적이라고 봅니다 — **단, 컵이 복원된다면**입니다.

- 판정이 **44 mm 차이**로 아주 여유롭고, 흔들림도 0.00 mm 로 안정적입니다
- 코드·좌표·IRD 를 하나도 안 바꿔도 됩니다 → 9/23 동결까지 일정에 여유가 생깁니다
- 복원이 안 되면 **㉠(테두리 파지)** 이 맞다고 봅니다. 그릇에서 이미 통하는 방식이고(낙하 0/10),
  얇은 데를 잡는 쪽이 이 그리퍼와 맞습니다. 다만 F1·IRD 변경이라 하루가 듭니다
- ㉡(컵 교체)은 9/23 동결까지 빠듯해 마지막 수단으로 두는 것이 좋겠습니다
