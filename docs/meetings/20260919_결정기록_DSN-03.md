## B. 오늘 정해야 하는 것 (25분)
| # | 안건 | 배경 | PM 제안 | 결정 |
|---|---|---|---|---|
| B1 | **반납 구역 방식** — 구역 + 탐색 파지(`RET_B`/`RET_C`, 탐색점 순회, `EMPTY_ZONE`) vs 고정 슬롯 | V-01(파지 폭 3상태) 결과가 근거. F1-02(9/20 오전)가 이 결정을 기다린다 | V-01에서 3상태 간격 ≥ 6 mm가 나오면 **구역 + 탐색 파지**(현재 문서 그대로). 안 나오면 고정 슬롯으로 범위 방어(SDD §9.9) | |
| B2 | **그릇 파지 방식** | 박진용 실측: 그릇 외경 114 mm > RG2 최대 폭 110 mm → 지름 방향으로 못 잡는다([CELL-02a 기록](../test_logs/20260918_CELL-02a_용기치수측정.md) §3). SDD §4.3의 `BOWL` 프리셋 예시는 실측 전 값 | **테두리(벽) 파지** — 폭·힘·접근 높이는 한석형이 V-01에서 정해 `cell.presets.BOWL`에. 털기·헹굼 때 버티는지는 V-16 | |
| B3 | **그리퍼 현재 폭을 읽는 경로** | 강사 배포 드라이버는 `OnRobotRGInput` 토픽을 내지 않는다. 나오는 것은 `/onrobot_joint_states`(JointState)뿐 → V-05 결과 | `motion.py`의 `setup_io(node)`에서 `/onrobot_joint_states`를 구독해 관절각 → 폭(mm) 환산(드라이버의 환산식 그대로). 안 되면 파지 성공 판정을 "명령 폭과 실제 정지 여부"로 단순화 | |
| B4 | **스펀지 홈 재파지** — 홈에 안착된 용기를 다시 잡을 때 폭으로 판정 가능한가 | V-15는 9/20 오후(티칭 2차 뒤)라 오늘은 방식만 | 방식은 그대로 두고 V-15 결과로 확정. 안 되면 재파지 폭 판정 생략(위치만 믿음) | |
| B5 | **HMI 설계** — 화면 구성 · `FlowState`/`FlowEvent` 필드 · 화면 방식 | F4-00 초안(황인재). 9/18에 화면은 **Next.js 정적 내보내기 + FastAPI 브리지**(프로세스 1개)로 하기로 했으나 문서에는 아직 `static/index.html` | F4-00 초안대로. 필드는 지금 msg에서 **추가만**(삭제·이름 변경 없음) → 민범진 flow 코드 영향 최소 | |
| B6 | **추가 토픽 `/cell/force`(10 Hz, 닦는 동안) · `/cell/grip_width`** 와 모니터·기록 노드 추가 여부 | 강사 산출물(힘 그래프)용 제안. 노드를 늘리면 구조 결정(노드 2개)과 부딪힌다 | 토픽 2개는 **추가**(발행은 `flow_node`의 통신 노드, 값은 기능 함수가 저장한 최신 값). **노드는 늘리지 않는다** — 기록은 hmi_bridge의 SQLite로 | |
| B7 | **실패 코드·정책** | `params.yaml`의 `flow.policy` 초안: `EMPTY_ZONE: next_zone` · `LEFTOVER_REMAIN`·`SEAT_FAIL: isolate` · `FORCE_LIMIT`·`TIMEOUT`·`RACK_JAM`·`TOOL_FAIL: retry:1->isolate` · `RACK_FULL`·`ROBOT_ERROR: pause` | 초안 그대로. 어떤 실패에서도 **툴은 홀더에 반납, 로봇은 안전 높이**(AGENTS §4) | |
| B8 | **YAML 키 이름 규칙** | SDD §4.3의 PM 제안(소문자 snake_case + 단위 접미사, ID는 대문자 그대로, 키 추가는 팀 공유) | 제안 그대로 + `flow.leftover_max_rounds` 키 추가(IRD §8 `leftover_loop(kind, 2)`의 2) | |
| B9 | **정지 방식** | `bootstrap.py`의 `shutdown()`이 `move_stop`을 `DR_QSTOP`(Stop Category 2)으로 부른다. Virtual에서는 모션 중 Ctrl+C 정지·재실행 확인 | 박진용(안전 담당)이 값 확인. 실기 확인은 V-24(선택). 급한 정지는 E-Stop | |
| B10 | **실기에서 rig를 손으로 돌릴 때 속도** | `PREWASH_VEL_SCALE`이 없으면 `vel_scale = 1.0`(= `cell.limits`의 속도 % 그대로). 런치는 기본 0.3 | 규칙으로: **실기 rig는 항상 `PREWASH_VEL_SCALE=0.3`부터**(AGENTS §3 규칙 1). 코드로 강제할지는 한석형 `motion.py` 구현 때 | |
