## 1. 무엇이 비어 있나

`cell.yaml` 의 안 채워진 키 **10개 중 8개**가 툴 프리셋입니다.

```
cell.presets.SPONGE.grip_width_mm · grip_zero_mm · grip_force_n · width_tol_mm
cell.presets.BRUSH .grip_width_mm · grip_zero_mm · grip_force_n · width_tol_mm
```

(나머지 2개는 `BOWL`·`CUP` 의 `approach_z_mm` — 집기(F1-02)에서 정해질 값입니다)

**이 값이 없으면 `f1.tool` 이 툴을 몇 mm 로 얼마나 세게 잡을지 모릅니다.** 시나리오 ③(툴 픽업 → 세제 → 닦기 → 툴 반납)이 통째로 막힙니다.

## 3. 🔴 PM 결정 요청 — **툴 파지 값은 누가 재나요?**

### ㉠ F1-03 담당이 잰다 (제 의견)

`SPONGE`·`BRUSH` 프리셋을 **읽는 코드는 `f1.tool` 하나뿐**입니다.

```
src/f1_handling/f1_handling/handling.py:81
    """툴 픽업/반납 … PICK: 홀더 상공 → 하강 → grip(프리셋) → 폭 확인 …"""
```

- 값을 **쓰는 사람이 재는 것**이 자연스럽습니다 — 폭 범위를 벗어나면 `TOOL_FAIL` 을 내는 판정도 같은 함수 안입니다
- V-08(툴 픽업·반납 10회)이 **어차피 그 값을 쓰는 시험**입니다. 따로 재면 같은 일을 두 번 합니다
- `cell.yaml` 프리셋의 주인은 규칙서상 **한석형**입니다(AGENTS §3 규칙 6)

### ㉡ 제가 재서 넘긴다

- 그릇·컵을 쟀던 것과 **같은 방법**이라 30분이면 됩니다
- 다만 **제 일정에 없는 일**이고, 9/22 오전은 F2 실기(V-16 넘어온 것)·UT-F2 가 있습니다

## 4. 왜 헷갈릴 수 있는지 — 미리 밝혀 둡니다

제가 **아니라고만 하면 떠넘기는 것처럼 보일 수 있어** 적습니다.

| 그래서 제 일처럼 보인다 | 실제 |
|---|---|
| `gripper.py`(`grip`·`grip_width`) 주인이 저입니다 | **도구**의 주인일 뿐, 값의 주인은 아닙니다 |
| 그릇·컵 프리셋을 **제가 쟀습니다**(V-01·V-05·V-23) | 그건 **F2 가 직접 쓰는 값**이라 그렇습니다 — 털기·담금의 미끄러짐 판정이 폭을 봅니다 |
| 측정 시험대 `rig_gripper.py` 가 제 것입니다 | 그래서 **§5 처럼 그대로 넘길 수 있습니다** |

🔑 **F2 는 툴 프리셋을 한 글자도 읽지 않습니다.** `flow.py` 는 `'SPONGE'`·`'BRUSH'` 라는 **이름만** `f1.tool` 에 넘깁니다.

```

    tool_id = 'SPONGE' if bowl else 'BRUSH'      # 값이 아니라 이름
```

## 5. 누가 하든 **제가 드릴 것** (㉠ 으로 정해져도 부담이 안 되게)

측정은 이미 만들어 둔 시험대로 **그대로 됩니다.** 새로 만들 것이 없습니다.

```bash
# 빈손 영점 — 그릇·컵과 같은 값입니다(10.58). 다시 안 재도 됩니다
# 툴을 그리퍼에 대 주고 폭만 재면 끝입니다
python3 src/cobot_common/test/rig_gripper.py v01 -n 10
```

| 드릴 것 | 내용 |
|---|---|
| 시험대 | `rig_gripper.py`(`v01` 3상태 · `v05` 흔들림 · `v23` 힘 전환) — 그대로 씁니다 |
| 영점 | **10.58 mm 그대로** — 빈손 영점은 **무엇을 잡든 같습니다**(9/21 V-01 확인) |
| 판정식 | 실폭 = `cc.grip_width()` − 10.58 (결정 E16 D-A) |
| 절차서 | `docs/test_logs/20260921_그리퍼세션_절차와기록_민범진.md` 그대로 |
| 곁에서 돕기 | 첫 1회는 같이 봐 드리겠습니다(15분) |

🚨 **주의 1가지** — 툴이 무르면 컵과 같은 문제가 납니다(끝까지 닫으면 눌리고, 덜 닫으면 빈손과 구분이 안 됨 · 결정 E19). 수세미는 물러 보이니 **고정 폭이 필요할 수 있습니다.** 재 보면 바로 압니다.
