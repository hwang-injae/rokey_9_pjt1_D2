# 방법론 — 힘제어·접촉 동작 (force.py · F3 닦기 · F1 탐색 하강·안착·삽입)

| 항목 | 내용 |
|---|---|
| 작성 | 박진용 (F3 · `cobot_common` 힘 함수 · 안전) · 2026-09-19 |
| 쓰는 곳 | `cobot_common/force.py`(INF-02b) · F3 `wipe_bowl`·`wipe_cup`(F3-02·03) · F1 `pick`·`place`·`rack_place` 의 접촉 구간 |
| 근거 | 두산 강의 자료(중급교육2 순응·힘 제어, 중급교육1 Move Periodic·Spiral) · 설치된 `DSR_ROBOT2.py`·`dsr_msgs2` · TS-01 |
| 🟡 | 숫자는 **시작값**이다. 실기 값은 V-03(힘제어 중 이동)·V-04·V-10·V-18 결과로 정하고 `cell.yaml`·`params.yaml` 에 적는다 |

## 1. 기본 순서 — 접촉 동작 하나
```
① 접근      : 위치 제어로 접촉 직전(수 mm~수십 mm 위)까지. 이동이 끝났는지 확인(mwait)
② 순응 ON   : task_compliance_ctrl(강성) — 목표 근처에서 켠다
③ 접촉·힘   : 순응 켠 채 짧게 내려가며 접촉을 찾거나(contact_down), 목표 힘을 건다(set_desired_force)
④ 감시 루프 : 힘 읽기·로그 → 도달 판정 → 힘 상한 → 위치 한계 → 타임아웃 (아래 §3)
⑤ 해제      : 힘 해제(release_force) → 순응 해제(release_compliance_ctrl) — 이 순서
⑥ 복귀      : 안전 높이로 (safe_retreat). ⑤·⑥은 어떤 실패에서도 반드시 (try/finally)
```

| 규칙 | 이유 |
|---|---|
| 순응을 **먼저** 켜고 힘을 건다 | 순응 없이 힘제어를 켜면 오류 2.1903 |
| 움직이는 중(비동기 이동)에 순응을 켜지 않는다 → 켜기 전 `mwait()` | 오류 2.1903 |
| 순응 중에는 **관절 이동(movej) 금지** — 직교 이동(movel·move_periodic·move_spiral)만 | 오류 2.1903. 컵 솔 회전도 툴 기준 직교 이동으로 |
| 순응 중 TCP 를 바꾸지 않는다(툴 무게는 바꿔도 됨) | 오류 2.1903 |
| 바깥 토크가 큰 상태(15 Nm 이상)에서 순응을 켜지 않는다 → 켜기 전 힘을 읽어 본다 | 오류 2.3501 |
| **툴 무게를 맞게 설정**한다(빈 그리퍼 / 툴을 쥔 상태) | 설정과 실제 무게의 차이가 그대로 외력으로 잡혀 처짐·충돌 알람·힘 값 오차 |
| 힘은 **상대 모드**(`DR_FC_MOD_REL`)로 건다 | 켜는 순간의 힘을 기준으로 삼아, 툴 무게 오차 같은 고정 옵셋이 목표 힘에 섞이지 않는다 |
| 힘 방향과 **다른 축**으로만 이동한다(예: Z 로 누르며 X·Y 로 닦기) | 힘과 같은 축의 이동은 동시에 할 수 없다 |
| 힘제어 중에는 속도를 따로 줄 수 없다 — 힘이 크면 빨리 움직이는 것처럼 보인다 | 목표 근처에서만 켜고, 힘은 작게 시작한다 |

## 2. 강성(stiffness) — 시작값
`task_compliance_ctrl(stx)` 의 `stx = [X, Y, Z, Rx, Ry, Rz]` (범위 X·Y·Z 0~20000 N/m, 회전 0~400 Nm/rad).

| 용도 | 시작값 | 뜻 |
|---|---|---|
| 접촉 하강·누르기 (Z 로 부드럽게, X·Y 는 단단히) | **[3000, 3000, 500, 100~200, 100~200, 200]** | Z 만 부드러워 닿아도 힘이 천천히 오른다. X·Y 는 위치를 지킨다 |
| 안착 탐색(홈에 맞추기) | X·Y 도 낮춤 🟡 V-04 | 옆으로 밀려 홈에 들어가게 |

- 강성이 낮을수록 외력에 부드럽게 반응하지만 위치 오차가 커지고 제자리로 돌아오는 데 오래 걸린다.
- 순응 상태에서 한 단계 내려가는 거리 × Z 강성 ≈ 그 단계에서 생기는 힘(예: 2 mm × 500 N/m ≈ 1 N). `contact_step_mm` 을 정할 때 쓴다.

## 3. 감시 루프 — 안전 3종을 "로직으로"
| 판정 | 방법 | 결과 |
|---|---|---|
| **도달** | 힘 크기가 **목표의 약 80%** 이상 → 도달로 본다 | 정확히 목표값에 닿기를 기다리다 무한 대기하는 것을 막는다. 비율은 🟡 V-03 |
| **힘 상한** | 힘 크기 > 상한(`limit_n`, 절대 상한 `force_max_n`) | 즉시 ⑤·⑥ → `FORCE_LIMIT` |
| **위치 한계** | 현재 Z 가 "여기보다 내려가면 안 되는 높이" 아래 → 관통·과삽입 | 즉시 ⑤·⑥ → `FORCE_LIMIT`(또는 `SEAT_FAIL`·`RACK_JAM` — 기능이 정한다) |
| **타임아웃** | 시작부터 `timeout_s` 초과 | ⑤·⑥ → `TIMEOUT` |

- 🚨 `check_force_condition(...)` 의 반환은 **만족 0 / 아니면 −1** (DRL 매뉴얼의 True/False 와 반대, TS-01 D). `if check_force_condition(...):` 로 쓰면 판정이 뒤집힌다 → 항상 `cobot_common.force_reached()` 를 쓴다. 강사 예제 `rokey/hw_gear_move.py` 도 이 형태라 그대로 옮기지 않는다.
- `check_force_condition` 은 **방향 없이 크기만** 비교한다(min·max 는 0 이상).
- 힘 값은 `get_tool_force()` — 힘은 BASE 기준(N), 모멘트는 TOOL 기준. 로그 열 `t, fx, fy, fz, target`(SDD §4.2).
- 감시는 **메인 스레드의 반복 루프 안에서** 짧은 주기(예 0.05~0.1 s)로 한다. 별도 스레드·타이머에서 로봇 함수를 부르지 않는다(SDD §3.2).

## 4. 툴·용기 놓침 감시 (그리퍼 폭)
- 쥔 직후 폭을 기억하고, 동작 중 주기적으로 다시 읽어 **기준에서 ± 허용치 이상 벗어나면**(밀림) 또는 빈손 폭 근처로 닫히면(빠짐) 즉시 멈추고 ⑤·⑥.
- 닦기(F3): 수세미 툴·솔 → `TOOL_FAIL` · 털기·헹굼(F2): 용기 → `GRIP_FAIL`.
- 폭을 읽는 경로는 DSN-03 B3·V-05 로 정한다([제안서](20260919_제안_RG2_폭_힘_경로.md)). 허용치는 🟡 V-18·V-16.
- 감시도 §3 과 같은 반복 루프 안에서 읽는다(스레드 아님).

## 5. 닦기·탐색 동작 만들기
| 동작 | 방법 | 비고 |
|---|---|---|
| 그릇 닦기 (F3-02) | Z 힘 유지 + X·Y 작은 원/나선 — `move_spiral`(툴 Z 축 기준, **시간 옵션**으로 속도 지정) 또는 `move_periodic`(X·Y 주기를 다르게) | 반경·회전수 조합에 따라 속도·가속도 오류가 날 수 있어 시간 옵션이 안전. 수세미 중심 이동 한계 10 mm(CELL-02a) |
| 컵 닦기 (F3-03) | 솔 삽입(접촉 하강) 뒤 **툴 Z 축 회전 왕복 + Z 상하 왕복**을 `move_periodic` 하나로(각 축 진폭·주기) | 관절 이동(J6 movej) 은 순응 중 금지 → 툴 기준 직교 모션. 진폭과 주기는 같은 축에 둘 다 넣는다(하나만 넣으면 오류 2.1218) |
| 안착 탐색 (F1-05 · V-04) | 순응 ON + 아래로 약한 힘 + X·Y `move_periodic` — 들어가면 깊이가 늘어난다 | 끝난 뒤 깊이·힘으로 판정 |
| 접촉 하강 (F1-02 탐색 파지 · 안착 · 삽입) | 순응 ON 상태로 짧은 단계씩 하강하며 매번 힘 확인(`contact_down`) | 도중에 멈추는 두산 파이썬 함수가 없어 단계 방식. 드라이버의 `motion/move_stop` 을 쓰는 방식은 V-24 이후 검토 |

## 6. 시험 순서
1. **로봇 없이(pytest)** — 가짜 두산 모듈로 호출 순서·판정·예외·설정 누락을 본다.
2. **Virtual** — 드라이버가 명령을 받아 주는지, 위치가 맞게 바뀌는지. 🚨 Virtual 에는 **힘·무게·접촉이 없다**(힘은 늘 0) · 가짜 그리퍼는 `'c'`·`'o'`·숫자(라디안)만, 폭·힘 값 없음.
3. **실기** — 첫 실기 `vel_scale 0.2~0.3`, E-Stop 담당 1명, 격리(`solo`, AGENTS 규칙 13). 힘 로그로 목표 ±2 N 안에 있는지, 상한 초과 시 후퇴하는지.
- 같은 함수를 **연속 3회 이상** 부른다(TS-01 B′ — "첫 번째만 되는" 결함).
