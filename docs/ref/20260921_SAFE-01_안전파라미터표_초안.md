## 3. 예외·오류 목록

### 3-1. 공정 실패 코드 (기능 함수가 돌려준다 → flow 정책)

| 코드 | 발생 | 처리 | HMI 표시 |
|---|---|---|---|
| `EMPTY_ZONE` | 집는 자리가 비었다 | 구역 종료 → 다음 구역(SKIPPED 기록) | 정보 |
| `LEFTOVER_REMAIN` | 털기 후에도 잔반이 임계 초과 | 격리 → 다음 용기 | 경고 |
| `SEAT_FAIL` | 안착 탐색 한도 초과 | 격리 | 경고 |
| `TOOL_FAIL` | 툴 폭 범위 밖(툴 없음) · 반납 때 바닥을 못 찾음 | 재시도 1회 → 격리 | 경고 |
| `GRIP_FAIL` | 털기·담금 중 미끄러짐 · 무게로 본 빈손 | **PAUSED → 사람이 확인**(9/20 E12) | 오류 |
| `FORCE_LIMIT` · `TIMEOUT` | 닦기·삽입·하강에서 상한·시간 초과 | 즉시 후퇴 → 재시도 1회 → 격리 | 경고 |
| `RACK_JAM` | 팔레트 삽입 걸림 | 후퇴 → 재시도 1회 → 격리 | 경고 |
| `RACK_FULL` | 팔레트 칸 소진 | PAUSED → 팔레트 교체 뒤 재개 | 오류 |
| `ROBOT_ERROR` | 아래 3-2 의 예외 · 두산 오류 · 충돌 정지 | **그 자리 정지 → PAUSED → 사람이 복구**(abort 거부) | 오류 |
| 통신 끊김 | `/flow/state` 2 s 이상 없음 | HMI 버튼 비활성 · 빨간 표시 | 오류 |

### 3-2. 코드 예외 (잡지 않고 위로 → flow 가 처리)

| 예외 | 뜻 | flow 처리 |
|---|---|---|
| `cc.MoveIncomplete` | 이동이 끝났는데 목표에서 2 mm/1° 넘게 떨어져 있다 — **로봇이 어디 있는지 모른다** | ROBOT_ERROR → PAUSED · 재시도·이어 하강 금지 |

| `cc.MotionHalted` | 강제정지(abort)로 이동이 끊김 | **중단 흐름으로**(ROBOT_ERROR 아님) — HOME → 툴 반납 → 격리 → HOME → 다음 용기 |
| `cc.ForceLimitError` · `cc.MotionTimeout` | 힘 함수의 상한·시간 초과 | 기능 함수가 `FORCE_LIMIT` · `TIMEOUT` 으로 바꿈 |
| `KeyError` | `cell.yaml`·`params.yaml` 값이 비어 있다 | **움직이기 전에** 멈춤 → ROBOT_ERROR(문구에 어느 키인지) |
| `ValueError` | 이름·kind·point 를 잘못 줌 · 힘 인자가 `force_max_n` 초과 | 움직이기 전에 멈춤 → ROBOT_ERROR |
