## 4. 막혔을 때

| 증상 | 무엇 | 어떻게 |
|---|---|---|
| `check` 가 `f1.pick 빈 껍데기` | 한석형 PR 이 아직 main 에 없다 | 시작하지 않는다. `git fetch` → PR 상태 확인 → 한석형에게 |
| 실기 중 `🚨 f1.pick 이 빈 껍데기다` 로 종료 | 위와 같음 (빌드가 옛것일 수도) | `cbc` 다시 → `check` |
| `EMPTY_ZONE` 로 멈춤 | 집는 자리에 용기가 없거나 폭 판정 밖 | 용기 확인 → 폭이 이상하면 한석형(프리셋 · E16) |
| `GRIP_FAIL` 로 멈춤 | 털기·담금 중 놓침 | E12 — 사람이 확인. 용기 위치 확인 뒤 HOME 으로 |
| `RACK_JAM` 로 멈춤 | 삽입 중 힘 초과 | 로봇은 그 자리. 용기 빼고 HOME. 칸 위치 재확인(§1 ④) |
| `EXC:MoveIncomplete` · `MotionHalted` | 로봇 위치를 모른다 | 🚨 **자동 이동 없음** — 사람이 복구(현재상황 §6). 브링업 재시작이 필요할 수 있다 |
| 첫 명령에서 안 끝남 · 두 번째부터 응답 없음 | 메인 스레드 규칙 위반 또는 잔류 프로세스 | TS-01 · `killdrcf` 뒤 브링업 다시 |
| 폭이 항상 같은 값 | 그리퍼 폭 구독이 안 붙음 | `/onrobot_joint_states` 확인 (V-05) |

혼자 값을 바꾸지 않는다. 좌표가 이상하면 ① 설정 키 ② 무엇이 어떻게 ③ 지금 막혔는지 → 황인재(E14).
