## 2. 측정 방법

로봇이 **그릇을 잡은 채 정지**한 상태에서, 자세 3개 × 상태 2개로 각 10회 측정한다.
1회 측정 = `reset_workpiece_weight` → 0.5 s 정지 → `get_workpiece_weight` **5회 평균**.

```bash
sod          # 두산 드라이버
# (실기 브링업은 ENV-02 담당인 한석형이 올린 뒤)
python3 tools/v02_weigh.py
```

| 단계 | 상태 | 자세 | 조작 |
|---|---|---|---|
| 1 | 빈 그릇 | P1 (기준 = `WEIGH` 후보 자세) | 자세 잡고 엔터 |
| 2 | 빈 그릇 | P2 | 자세 바꾸고 엔터 |
| 3 | 빈 그릇 | P3 | 자세 바꾸고 엔터 |
| 4 | — | — | **그릇에 잔반 대용품 투입** (사람이 손으로) |
| 5 | 대용품 | P1 | 자세 잡고 엔터 |
| 6 | 대용품 | P2 | 자세 바꾸고 엔터 |
| 7 | 대용품 | P3 | 자세 바꾸고 엔터 |
