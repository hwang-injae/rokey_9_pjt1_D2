# CELL-02a 용기·툴 치수 측정 — 시험 기록

| 항목 | 내용 |
|---|---|
| taskID | **CELL-02a** — 용기 치수 측정·스펀지 홈 커팅 도면·툴 홀더 위치 결정 (일정표) |
| 담당 | 박진용 (F3) |
| 일시 | 2026-09-18 저녁 측정 · 2026-09-19 저장소 기록 |
| 모드 | 로봇 없음 (자·버니어 실측) |
| 결과 | 그릇·컵·수세미 측정 완료, 솔은 맞춤 제작 설계 확정 |

## 1. 측정값
### 그릇 (BOWL)
| 항목 | 값 |
|---|---|
| 외경 | 114 mm |
| 벽 두께 | 2 mm |
| 내경 (= 바닥 지름) | 110 mm (114 − 2×2) |
| 내부 높이 | 45 mm |

### 컵 (CUP) — 아래로 갈수록 좁아지는 모양
| 항목 | 값 |
|---|---|
| 상단 외경 / 내경 | 75 / 73 mm |
| 하단 외경 / 내경 | 55 / 53 mm |
| 내부 높이 | 95 mm |

### 수세미 (그릇용 `SPONGE` 툴)
| 항목 | 값 |
|---|---|
| 지름 | 90 mm |
| 높이 | 45 mm |

### 솔 (컵용 `BRUSH` 툴) — 맞춤 제작 설계
- 길이 = 컵 내부 높이 **95 mm**. 솔 윗부분을 그리퍼가 쥔다.
- 컵 안쪽 기울기(위 Ø73 → 아래 Ø53)에 맞물리는 모양.
- 동작: 넣은 뒤 제자리 회전 + 위아래 짧은 왕복(스트로크).

## 2. 설계에 쓰는 값
| 값 | 근거 | 쓰는 곳 |
|---|---|---|
| 수세미 중심 이동 한계 **10 mm** | 그릇 안쪽 반지름 55 − 수세미 반지름 45 | `f3.wipe_bowl.radius_mm` 최대 9 mm(여유 1 mm). 큰 나선이 아니라 가운데의 작은 원 |
| 컵 삽입 최대 깊이 **< 95 mm** | 솔 길이 = 컵 내부 높이 → 끝까지 넣으면 그리퍼가 컵 윗면에 닿는다 | `f3.wipe_cup.insert_depth_mm` 는 95 보다 얕게, 실제 정지는 삽입 힘(`cell.limits.insert_limit_n`)으로. V-10 에서 확정 |

## 3. 확인할 것 (다음 검증)
| # | 내용 | 어디서 |
|---|---|---|
| 1 | **그릇은 지름 방향으로 잡을 수 없다** — 외경 114 mm > RG2 최대 폭 110 mm. 테두리를 잡는다 | F1(한석형) 프리셋 · V-01 |
| 2 | 용기는 스펀지에 깊이 넣지 않는다(9/19 박진용). 홈 깊이·지름은 고정틀 제작 때 정한다 | CELL-02 · V-12 |
| 3 | 솔이 컵에 맞물린 채 돌리면 **컵이 같이 돌 수 있다** · 삽입 중 마찰이 쌓여 바닥 전에 삽입 힘 상한에 걸릴 수 있다 | V-10 |
| 4 | 닦는 힘(3~5 N)에서 수세미 툴·솔이 그리퍼 안에서 밀리거나 돌지 않는가 | V-18 |
| 5 | 툴을 쥐면 툴 무게가 바뀐다 — 툴 무게 설정이 틀리면 힘 값이 틀어지고 처짐·충돌 알람(초급 교육 "툴 무게") | F1 `tool()` 과 협의 |

## 4. `params.yaml` 의 `f3` 절 초안 (config 골격 INF-04 가 들어오면 반영)
키 규칙은 SDD §4.3(단위 접미사, 값 옆 주석). 공용 값(삽입 힘 상한·타임아웃·안전 높이)은 `cell.yaml` 을 읽으므로 여기 두지 않는다.
```yaml
f3:                                   # ── f3 절 (박진용) ──
  soap:
    depth_mm: 40                      # 담금 깊이, F3-03 에서 확정
    hold_s: 0.5                       # 담금 유지, F3-03 에서 확정
  wipe_bowl:
    target_force_n: 4.0               # 3~5 N (FR-08), V-03·F3-02 에서 조정
    limit_n: 10.0                     # NFR-01 닦기 10 N
    radius_mm: [2, 9]                 # 수세미 중심 이동 한계 10 mm (이 기록 §2)
    turns: 4                          # F3-02 에서 확정
    duration_s: 15                    # 타임아웃, F3-02 에서 확정
  wipe_cup:
    insert_depth_mm: 90               # 최대 삽입 깊이 < 95 (그리퍼-컵 윗면 여유), V-10 에서 확정
    rot_deg: 180                      # 회전각 (SR-09 ±180°), F3-03 에서 확정
    cycles: 4                         # F3-03 에서 확정
    stroke_mm: 30                     # F3-03 에서 확정
    limit_n: 10.0                     # NFR-01 닦기 10 N (회전·스트로크 구간)
```
