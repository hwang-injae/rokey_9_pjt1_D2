## 1. 절차 — 터미널 2

### ① `move_to` — 빈손으로 자리 이동 3회
```bash
cd ~/rokey9_pjt1/rokey_pjt01_ws_f4 && cbc && PREWASH_VEL_SCALE=0.3 python3 src/f1_handling/test/rig_f1.py move_to --station WEIGH --kind BOWL
```
- `-n 3` 이 기본이라 **연속 3회** 돈다. 매회 `Result(ok=True, code='OK')` 가 나와야 한다.
- 🚨 **첫 이동 전에 로봇이 HOME 에 있는지** 본다. 임의 자세(특히 곧게 편 자세)에서 시작하면 직선 이동이 안 먹을 수 있다.
  필요하면 먼저: `python3 src/f1_handling/test/rig_f1.py move_to --station HOME -n 1`

### ② `place` — **빈손으로 한 번** (자리·높이 확인)
```bash
PREWASH_VEL_SCALE=0.3 python3 src/f1_handling/test/rig_f1.py place --station SPONGE_BED_B -n 1
```
- 빈손이라 놓을 것은 없다. **내려간 높이가 홈 바닥과 맞는지**만 눈으로 본다(용기를 박지 않는지).

### ③ `place` — **그릇을 쥐여 주고** 3회
그리퍼에 그릇을 물린 뒤:
```bash
PREWASH_VEL_SCALE=0.3 python3 src/f1_handling/test/rig_f1.py place --station SPONGE_BED_B
```

### ④ `place` — **컵을 쥐여 주고** 3회
```bash
PREWASH_VEL_SCALE=0.3 python3 src/f1_handling/test/rig_f1.py place --station SPONGE_BED_C
```

### ⑤ 격리 자리 — 접근점 없는 자리 (9/21 찍음)
🚨 **HOME 에서 시작한다** — 먼저 `python3 src/f1_handling/test/rig_f1.py move_to --station HOME -n 1`.
격리 자리는 로봇 **뒤쪽을 돌아 왼쪽**이다(J1 −264°). 자세는 9/21 에 확인했지만 **HOME 에서 관절값으로 곧장 가는 길은 처음**이다 —
허리를 돌리면서 팔을 뻗어 툴 홀더·헹굼 수조·잔반통 위를 지나간다. 걸릴 것 같으면 E-Stop.
```bash
PREWASH_VEL_SCALE=0.3 python3 src/f1_handling/test/rig_f1.py place --station ISOLATE --kind BOWL -n 1
```

| ☐ | 그리퍼가 **실제로 열리는가** (Virtual 에서 확인 불가했던 것) | 안 열리면 F1 문제가 아니라 그리퍼 함수·프리셋 문제 — 민범진과 |

| ☐ | 이동 도중 멈춤(`MoveIncomplete`) 0회인가 | 나면 그 구간은 V-22 로 되돌아간다 |

## 4. 막혔을 때

| 증상 | 조치 |
|---|---|
| `RuntimeError: 그리퍼 명령 … 실패` | 그리퍼 드라이버·프리셋 문제(F1 아님) → 민범진. 이동만 보려면 `--no-gripper` 를 붙인다 |
| `KeyError … place_clear_mm` | `params.yaml` 의 f1 절 — main 최신인지 확인 |
| `KeyError … cell.yaml 의 … 비어 있다` | 그 자세가 아직 안 찍혔다. **안 움직이는 것이 정상** |
| 용기를 떨어뜨림 | 파지 힘(`cell.presets.*.grip_force_n`)을 올린다 — 한석형·민범진 |
| 되올라올 때 끌고 옴 | 위 🔎 표의 첫 줄. 임시로는 `place_clear_mm` 을 키우지 말 것(원인이 다르다) |
