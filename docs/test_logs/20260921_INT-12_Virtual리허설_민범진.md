## 무엇을 봤나

| | 그릇 a | 그릇 b | 컵 a | 컵 b |

| 3회차 가짜 잔반 100 g | 털기 4주기 → HOME 경유 → 재측정 0 g → `rounds=1` ✅ | — | 같음 ✅ | — |

- **12a**: `pick`(빈 껍데기·🟡) → `move_to('WEIGH', True, kind)` → `leftover_loop(kind, 2)`. 잔반 없는 회차 ≈ 4~5 s, 잔반 회차(털기 + HOME 경유 2번) ≈ 28~30 s
- **12b**: `pick(SPONGE_BED_*)`(빈 껍데기·🟡) → `dip('RINSE',1)` → `shake('RINSE',3)` → `rack_place`(빈 껍데기·🟡) → `move_to('HOME', False)`. 회차당 ≈ 20~21 s로 일정(SDD §3.2 ⑧ "첫 번째만 되는" 결함 없음)
- `RINSE` 는 접근점이 있어 담금·털기마다 **163.6 mm 더 내려간다**(그릇·컵 같음) — 현재상황 §7 의 "RINSE.CUP 끝점 158 mm 내림" 과 숫자가 다르다. 🟡 좌표 담당(황인재) 참고 — 동작에는 문제 없었다
- 회차 사이 "용기 다시 놓기" 는 `< /dev/null` 로 넘겼다(사람 없음)
