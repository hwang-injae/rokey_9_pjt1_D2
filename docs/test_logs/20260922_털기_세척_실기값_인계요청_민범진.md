## 1. 넘기는 것 — 털기 실기값 (제 F2 · 넘길 수 있습니다)

### ① 잔반 버리기(WASTE) — "임팩트 있게"
```yaml
f2.shake.WASTE: {joint: 5, amp_deg: 15, cycles: 4, period_s: 0.6, tilt_deg: -90}
```
- ✅ 9/22 실기로 **된다는 것까지** 확인: 저속 1회 알람 0 · 미끄러짐 0.3 mm → 원속에서 추 107 g **털리는 것 눈으로**
- 🟡 **안 한 것**: 시연에서 보기 좋을 만큼 **세고 빠르게** 맞추기. 지금은 "되는 최소값" 상태입니다
- 기울기 −90° 는 `rig_jog` 실측(J5 90 → 0 에서 입이 잔반통 쪽 · posj [-180, 0, 90, 0, 0, 180])

### ② 물 털기(RINSE) — 값 자체가 미정
```yaml
f2.shake.RINSE:
  BOWL: {joint: 5, amp_deg: 10, period_s: 0.5}   # 🟡 시작값
  CUP:  {joint: 5, amp_deg: 6,  period_s: 0.6}   # 🟡 시작값 · 컵은 HOLD 불가(E19)
```
- 9/22 12:5x 담금 3/3 OK · J5 가 까딱 방향인 것 확인. **흔들기 값은 한 번도 실기 안 함**

### ③ V-16 (세게 쥐기 최소 힘)
- 지금 35 N 으로 털기·담금 모두 낙하 0 — **"35 N 유지" 로 닫아도 된다**고 봅니다. 더 낮추려면 그때 ①②와 같은 세션에서

### 도구 — 키보드로 값 바꾸고 바로 흔들어 봅니다 (파일 안 고침)
```bash
python3 src/f2_sense_flow/test/rig_f2.py grip --kind BOWL            # 먼저 용기를 쥔다
python3 src/f2_sense_flow/test/rig_shake_tune.py --mode WASTE --kind BOWL   # 잔반 버리기
python3 src/f2_sense_flow/test/rig_shake_tune.py --mode RINSE --kind BOWL   # 물 털기 (컵은 --kind CUP)
```
| 키 | 뜻 |
|---|---|
| `v` | 속도 30 % ↔ 100 % (**첫 시도는 30 %**) |
| **스페이스** | 지금 값으로 흔든다 (진짜 `sense.shake` — 자리로 가서 쥐고 흔들고 되돌아옴) |
| `A`/`a` | 폭 ±5° · `P`/`p` 주기 ±0.05 s(작을수록 빠름) · `T`/`t` 기울기 ±10°(WASTE) · `N`/`n` 횟수 ±1 |
| `w` | 지금 값을 params 줄로 출력 → 그 줄을 `params.yaml` 에 |
| `q` | 끝 |

**한 번에 한 가지만** 바꾸고 스페이스 — 뭐가 효과인지 보입니다.
**멈출 신호**: 로그 `폭 … 변함 > 허용`(미끄러짐) · `상한 … 늘린다`(관절 속도 한계 — 더 빨라지지 않음) · 잔반통/수조 벽 접촉 · 알람

**결과 넣을 곳**: `params.yaml` 의 `f2.shake.WASTE` · `f2.shake.RINSE.BOWL/CUP` 세 줄. 제 절이지만 **이 세 줄은 직접 적으셔도 됩니다**(민범진 동의 · 🟡 표시 지우고 실기 근거 한 줄).

## 2. 세척(SOAP·WIPE) — 🔴 제가 넘길 수 없습니다, PM 결정이 필요합니다

`f3.soap` · `wipe_bowl` · `wipe_cup` 은 **박진용(F3)** 담당입니다(일정표 F3-02 · F3-03 · V-10 · UT-F3). AGENTS §2 "남의 기능 코드를 만들지 않는다" 라 제가 인계를 정할 수 없습니다.

세척 동작도 F4 가 맡기를 원하시면:
- 박진용과 합의 → 결정기록에 한 줄(E22 때처럼) → 일정표 담당 변경
- 지금 박진용 쪽 남은 것: 그릇 닦기 재검증(툴·TCP 풀림 구간이라 다시) · soap 실기 · F1-05 안착 · UT-F3

제 의견: 박진용이 오늘 오후 F1-05 안착까지 맡고 있어 **세척까지 F4 로 옮기면 저녁 INT-13 주도가 붕 뜹니다.** 세척은 박진용이 계속하고, **털기만 F4** 가 가져가는 쪽을 제안합니다.
