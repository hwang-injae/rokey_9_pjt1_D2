## 넘기는 세 가지

### ① 헹굼 담금 (`f2.dip`) — 그릇 ✅ · 컵 🟡
```yaml
f2.dip.RINSE: {depth_mm: 60, hold_s: 1.0}        # 수조 위 티칭 자세에서 아래로 60 mm → 1 s → 되올라옴
flow.counts.rinse_dips: 2                        # 🔄 9/22 1 → 2 (민범진)
```
| | 상태 |
|---|---|
| 그릇 | ✅ 9/22 12:5x 실기 **3/3** — 수조 자세 도달(접근점 → 163.6 mm 하강) · 60 mm 내려갔다 올라옴 · **바닥 접촉 없음** · 폭 변화 0.2 mm |
| 컵 | 🟡 **한 번도 안 함** — 컵 헹굼 자세(`RINSE.CUP`)가 "처음 돌릴 때 눈으로" 표시 · 끝점이 −13.6, 158 mm 내려간 값 · 컵은 HOLD 불가(E19) |
| 정할 것 | 컵 `depth_mm` 가 수조 바닥을 안 찍는지 · 담금 2회가 적당한지 |
- 🚨 담금 하강은 **힘 감시가 없는 자유 이동**입니다(물 없음 전제). 티칭이 어긋나면 용기 바닥이 수조 바닥을 찍습니다 → **첫 컵은 반드시 저속**

### ② 잔반 버리기 (`f2.shake` WASTE) — "임팩트" 미조정
```yaml
f2.shake.WASTE: {joint: 5, amp_deg: 15, cycles: 4, period_s: 0.6, tilt_deg: -90}
```
- ✅ **되는 것까지** 확인(9/22): 저속 1회 알람 0 · 미끄러짐 0.3 mm → 원속에서 추 107 g **털리는 것 눈으로**
- 🟡 **안 한 것**: 시연에서 보기 좋을 만큼 세고 빠르게. 지금은 "되는 최소값" 입니다
- 기울기 −90° 는 `rig_jog` 실측(J5 90 → 0 에서 입이 잔반통 쪽 · posj [-180, 0, 90, 0, 0, 180])

### ③ 물 털기 (`f2.shake` RINSE) — 값 자체가 미정
```yaml
f2.shake.RINSE:
  BOWL: {joint: 5, amp_deg: 10, period_s: 0.5}   # 🟡 시작값
  CUP:  {joint: 5, amp_deg: 6,  period_s: 0.6}   # 🟡 시작값 · 컵은 HOLD 불가라 약하게
```
- J5 가 "까딱" 방향인 것만 확인(9/22). **흔들기는 한 번도 실기 안 함**
- 종류별로 나뉘어 있어 **둘 다 채워야** 합니다(한쪽만 있으면 시작 전 KeyError)

## 도구 — 키보드로 값 바꾸고 바로 해 봅니다 (파일 안 고침)

```bash
git pull && cbc
ros2 service call /dsr01/dsr_controller2/tcp/get_current_tcp dsr_msgs2/srv/GetCurrentTcp   # GripperDA_v1 (TS-07 · E26 확인만)
python3 src/f2_sense_flow/test/rig_f2.py grip --kind BOWL      # ① 용기를 쥔다 (열림 → Enter → 폭 확인)
```

**털기 — 튜닝 시험대**
```bash
python3 src/f2_sense_flow/test/rig_shake_tune.py --mode WASTE --kind BOWL   # 잔반 버리기
python3 src/f2_sense_flow/test/rig_shake_tune.py --mode RINSE --kind BOWL   # 물 털기 (컵은 --kind CUP)
```
| 키 | 뜻 |
|---|---|
| `v` | 속도 30 % ↔ 100 % (**첫 시도는 30 %**) |
| **스페이스** | 지금 값으로 흔든다 — 진짜 `sense.shake`(자리로 가서 쥐고 흔들고 되돌아옴) |
| `A`/`a` 폭 ±5° · `P`/`p` 주기 ±0.05 s(작을수록 빠름) · `T`/`t` 기울기 ±10°(WASTE) · `N`/`n` 횟수 ±1 | |
| `w` | 지금 값을 params 줄로 출력 → 그 줄을 `params.yaml` 에 |
| `q` | 끝 |

**헹굼 담금 — 값 바꿔 가며**
```bash
PREWASH_VEL_SCALE=0.3 python3 src/f2_sense_flow/test/rig_f2.py dip --kind CUP --count 1 -n 1   # 컵 첫 시도는 반드시 저속
python3 src/f2_sense_flow/test/rig_f2.py dip --kind BOWL --count 2 -n 3                        # 그릇 · 실제 횟수로 3회 연속
```
깊이를 바꿔 보려면 `params.yaml` 의 `f2.dip.RINSE.depth_mm` (상한 `f2.limits.max_depth_mm` 150).
수조 안에서 자세를 눈으로 잡고 싶으면 조그: `rig_jog.py --goto RINSE --kind CUP --carrying` → `z` 로 위아래.

**한 번에 한 가지만** 바꾸고 해 보기 — 뭐가 효과인지 보입니다.
**멈출 신호**: `폭 … 변함 > 허용`(미끄러짐) · `상한 … 늘린다`(관절 속도 한계) · 수조/잔반통 벽·바닥 접촉 · 알람 · 컵 낙하(눈으로 · 무게로는 못 잡음 E19 ③)
