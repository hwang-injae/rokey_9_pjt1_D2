## 2. 무엇을 알았나

1. **단위가 kg** 이었다. 9/18 V-02 는 펜던트 화면(N)을 손으로 읽은 것이라 이 경로의 단위를 몰랐고, 오늘이 이 경로로 읽은 첫 값. g 로 계산하면 "0 g" → `min_net_g` 하한에 걸려 **GRIP_FAIL** 이 난다(오늘 첫 실행에서 그렇게 멈췄다 — 시험대는 설계대로 로봇을 세웠다).
2. **자세마다 오차가 다르다** (z 77 mm 차이로 60 g). 원인은 **그리퍼 무게·무게중심 미등록**(요구사항엔 있고 일정표엔 없음) → `docs/meetings/20260921_확인요청_툴무게등록_민범진.md`. PM 이 9/22 오전 등록.
3. 마이너스 오차 자세에서는 값이 0 에 잘려 **빈 용기값 상쇄가 성립하지 않는다.** 등록 뒤에도 빈손 값이 0 근처면 자세를 옮긴다.
4. 그 밖: `rig_weigh_probe` 첫 실행 1회가 첫 조회에서 멈춤(Ctrl+C) — 서비스 자체는 정상(`ros2 service call` 즉답). 앞 프로그램 종료 직후 겹침으로 추정, 재현 안 됨. 🟡 재발하면 TS 기록.
