# SAFE-01 실측 — 실행 순서 (복붙용) · 박진용 9/21

> 명령을 위에서부터 하나씩 복붙해 실행하고, **나오는 출력을 통째로 복붙**해서 보내면 된다.
> 값 채우기·판정은 내가 한다. 눈으로 보는 것(STEP A2/A3/A4)만 짧게 답하면 된다.

---

## STEP 0 — 준비 (한 번, 로봇 안 움직임)

```bash
mkdir -p ~/safe01 && cd ~/cobot1/rokey_9_pjt1_D2 && git log --oneline -1 && echo "--- ros ---" && echo $ROS_DOMAIN_ID $ROS_LOCALHOST_ONLY && grep -n "vel_scale" src/cobot_common/config/params.yaml
```
→ 출력 복붙.

🚨 실행 전 눈으로: 스펀지 홈에 **그릇**, 그리퍼에 **수세미 툴**, E-Stop 에 손.

---

## STEP A — 그릇 닦기 3회 (약 2분)

```bash
cd ~/cobot1/rokey_9_pjt1_D2 && soc && python3 src/f3_wipe/test/rig_f3.py bowl 2>&1 | tee ~/safe01/A_bowl.txt
```

끝나면:

```bash
cat ~/safe01/A_bowl.txt
```
→ 통째로 복붙. (너무 길면 아래 요약만)

```bash
grep -E "바닥:|나선 끝:|누르는 힘 평균|WipeResult|MoveIncomplete|실패|🚨" ~/safe01/A_bowl.txt
```

### A2 — 눈·귀 (이 4줄만 답해주면 된다)
```
회전방향: 반대 / 같음 / 안보임
작업대울림: 없음 / 약간 / 심함
경고음: 안남 / 남
그릇밀림: 없음 / 조금 / 많이
```
> 방향이 안 보이면 `spiral_pitch_mm` 을 2.0 으로 잠깐 낮추면 바퀴 수가 7로 늘어 잘 보인다(보고 나서 5.0 으로 되돌린다).

### A3 — V-18 툴 파지 → ✅ **안 한다** (9/19~9/20 실기 결과로 갈음). 눈에 띄는 어긋남이 있을 때만 알려주면 된다.

### A4 — 후퇴 높이 (닦기 끝나 올라온 자리에서)
```
수세미 아랫면 ~ 그릇 테두리 간격: ___ mm
```
