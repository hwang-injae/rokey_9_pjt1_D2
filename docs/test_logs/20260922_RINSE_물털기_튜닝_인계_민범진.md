## 0. 지금 상태

```yaml
f2:
  shake:
    RINSE:                                   # 물 털기 = 그리퍼 까딱까딱 (5번 관절 · 기울이기 없음 · 입은 위)
      BOWL: {joint: 5, amp_deg: 10, period_s: 0.5}   # 🟡 시작값
      CUP:  {joint: 5, amp_deg: 6,  period_s: 0.6}   # 🟡 시작값 — 컵은 HOLD 가 안 돼(E19) 약하게
```
- 9/22 12:5x 실기: 수조 자세 도달 · 담금 3/3 OK · **5번 관절이 "까딱" 방향**인 것 확인(민범진). 흔들기 값은 아직 안 정함
- 원하는 그림: **임팩트 있게** — 폭(amp_deg)과 주기(period_s)로. 관절 속도 상한(100°/s × vel_scale)에 걸리면 코드가 시간을 늘리고 경고를 남긴다

## 2. 그릇 — 튜닝 시험대 (키로 값 바꾸고 스페이스로 흔든다)

```bash
python3 src/f2_sense_flow/test/rig_shake_tune.py --mode RINSE --kind BOWL
```
시작하면 문지기 → HOME. 그 뒤 키:

| 키 | 뜻 |
|---|---|
| `v` | 속도 30 % ↔ 100 % (**처음엔 `v` 로 30 % 만든 뒤** 스페이스) |
| **스페이스** | 지금 값으로 흔든다 — 첫 번엔 수조 자세로 가서(접근점 → 163.6 mm 하강) 35 N 으로 쥐고 왕복 → 20 N |
| `A` / `a` | 폭 +5° / −5° |
| `P` / `p` | 주기 +0.05 / −0.05 s (작을수록 빠름) |
| `N` / `n` | 횟수 ±1 |
| `w` | 지금 값을 params 줄로 출력 → **이 줄을 params.yaml 에** |
| `q` | 끝 |

순서 추천: `v`(30 %) → 스페이스 → `v`(100 %) → 스페이스 → `A` 몇 번 · `p` 몇 번 씩 올리며 스페이스 → 마음에 들면 `w`.

**볼 것**: 그릇이 수조 벽에 닿는지 · 로그 `폭 … 변함 > 허용` (미끄러짐 → GRIP_FAIL) · 알람 · `상한 … 늘린다` 경고(= 더 못 빨라짐)

| 그릇 결과 | 값 |
|---|---|
| 벽 안 닿는 최대 폭 | `______ °` |
| 정한 값 (`w` 줄) | `BOWL: {joint: 5, amp_deg: ____, period_s: ____}` |
| 미끄러짐·알람 | 없음 / ______ |
