### 판정

```

### 🆕 결정 E16 으로 **영점까지 정해야 합니다**

`grip_zero_mm` = **빈손으로 꽉 닫았을 때 읽히는 폭**. 판정식이 `읽은 폭 − 영점` 이 됩니다.

| | 빈손 폭(= 영점) | 그 힘 |
|---|---|---|
| **BOWL** (NORMAL 20 N) | ______ mm | ___ N |
| **BOWL** (HOLD 35 N) | ______ mm | ___ N |
| **CUP** (NORMAL 15 N) | ______ mm | ___ N |
| **CUP** (HOLD 30 N) | ______ mm | ___ N |

🚨 **영점은 힘에 따라 달라집니다**(고무가 눌려서 0.2~0.4 mm). **판정에 쓸 힘과 같은 힘**으로 재야 합니다.

### 👉 한석형님·PM 께 넘길 값 (세션 끝나고 바로)

```

cell.presets.BOWL.width_tol_mm   = ______     ← 흔들림보다 크고 간격의 절반보다 작게
cell.presets.CUP.grip_zero_mm    = ______

## 5. 🚨 중단선 — 세션 중에 고민하지 않기

| 상황 | 그때는 |
|---|---|
| **A** §1 에서 힘이 안 읽히거나 10 s 타임아웃이 남 | 코드 문제. **V-01 만 하고 접는다**(폭 읽기는 영향 없음). 원인은 저녁에 |
| **B** probe 영점이 3회 다 다름(±1 mm 초과) | 영점을 설정에 못 넣는다. **V-01 값만 받아 적고** 영점은 저녁에 다시 |
| **C** V-01 이 20분을 넘김 | **V-23 을 버리고 V-01 을 끝낸다.** 내일 집기가 V-01 을 기다린다 |
| **D** 그릇이 자꾸 떨어짐 | 핑거 패드 확인 → 그래도 안 되면 **힘을 올려** 다시. 기록에 남긴다 |
| **E** 안전 스위치가 걸림(전혀 안 움직임) | **컴퓨트박스 전원 재투입.** 코드로는 못 푼다 |

**우선순위**: V-01 > V-23 > V-05 자로 대조 > 그 외
