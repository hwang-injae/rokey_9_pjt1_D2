## 1. V-02 — 빈 그릇 기준값

**무엇을 하나**: 잔반이 있는지 없는지는 `지금 무게 − 빈 용기 무게` 로 판단한다.
그 **빈 용기 무게**를 오늘 자세에서 다시 잰다.

🚨 저울로 잰 '진짜 무게' 가 아니다. 로봇 하중에는 옵셋(+42~45 g)이 있어서
**같은 자세에서 로봇이 읽은 값**이어야 판정식에서 상쇄된다.

```bash
python3 src/f2_sense_flow/test/rig_f2.py release
```
→ 그리퍼가 열린다. **빈 그릇을 그리퍼 사이에 대 준다** (벽을 세로로)

```bash
python3 src/f2_sense_flow/test/rig_f2.py grip --kind BOWL
```
- [ ] `영점 뺀 폭` 이 **2.15 ± 0.6 mm** 안인가 → `______ mm`
- [ ] 🚨 `목표에 그대로 도달했다` 경고가 나오면 **그릇이 안 물린 것**이다. 다시 대 준다

```bash
python3 src/f2_sense_flow/test/rig_f2.py weigh --kind BOWL -n 3
```
→ 로봇이 `WEIGH` 자세로 간다. 🚨 **쥔 그릇이 뒤 용기·공급 구조에 닿지 않는지 눈으로 본다**
(닿으면 무게가 틀린다)

```bash
python3 src/f2_sense_flow/test/rig_f2.py empty --kind BOWL -n 10
```

## 2. 컵 — 78 mm 로 **진짜 들리는지** (🔴 E19 가 남긴 숙제)

**무엇을 하나**: 컵은 폭으로 "잡았나" 를 판정하지 않기로 했다(E19). 그래서
**78 mm 가 실제로 컵을 붙잡는 폭인지 아무도 확인한 적이 없다.**

컵은 아래로 갈수록 좁다(상단 75 · 하단 55). 잡는 높이의 지름이 **67.4 mm**
(= 78 − 영점 10.58)보다 작으면 **손가락이 컵에 안 닿는다.**

```bash
python3 src/f2_sense_flow/test/rig_f2.py release
```
→ **컵을 바닥에 세워 두고** 그리퍼 사이에 오게 한다 (손으로 들고 있지 않는다)

```bash
python3 src/f2_sense_flow/test/rig_f2.py grip --kind CUP
```
→ 5 N 으로 78 mm 까지 닫는다

## 3. V-07 — 털기

**무엇을 하나**: 잔반통 위에서 흔들 때 **로봇이 "부딪혔다" 고 잘못 판단해 멈추는지** 본다.

🔔 잔반 대용품은 **없어도 된다.** V-07 의 합격 기준은 "충돌 감지 오작동" 뿐이고,
"진짜로 털려 나가는가" 는 나중 F2-01 이다.

🔔 `shake` 는 **자동으로 HOME 을 거쳐서** 간다(결정 E15 — 잔반통은 로봇 뒤, 저울은 앞).
앞뒤로 곧장 가면 몸통을 가로지르고 6번 관절이 꼬인다.

### 그릇

```bash
python3 src/f2_sense_flow/test/rig_f2.py release
# (빈 그릇을 대 준다)
python3 src/f2_sense_flow/test/rig_f2.py grip --kind BOWL
python3 src/f2_sense_flow/test/rig_f2.py shake --mode WASTE --kind BOWL -n 10
```

| | 값 |
|---|---|
| 멈춤(충돌 감지) | `______ / 10` |
| 낙하 | `______ / 10` |
| 폭 변화 최대 | `______ mm` (기준 ≤ 1.0 = `slip_tol_mm`) |
| 한 번에 걸린 시간 | `______ s` (설정 주기 0.6 s · 9/20 측정 1.099 s) |

**합격**: 멈춤 **0 / 10**
- 멈추면 → 진폭을 줄인다: `params.yaml` `f2.shake.WASTE.amp_deg` 15 → 12 → 10

### 컵 — 🔴 여기가 오늘의 핵심

E19 ② 때문에 컵은 **힘을 세게 바꾸는 것(HOLD)이 안 먹는다.** 5 N 그대로 버텨야 한다.

```bash
python3 src/f2_sense_flow/test/rig_f2.py release
# (컵을 대 준다)
python3 src/f2_sense_flow/test/rig_f2.py grip --kind CUP
python3 src/f2_sense_flow/test/rig_f2.py shake --mode WASTE --kind CUP -n 10
```

| | 값 |
|---|---|
| 멈춤 | `______ / 10` |
| **낙하** | `______ / 10` ← 🔴 이게 1 이라도 나면 E19 를 다시 봐야 한다 |

**떨어지면**: 진폭을 줄여 본다(15 → 10 → 8). 그래도 떨어지면 **멈추고 PM 에 보고**한다
(컵 파지 방식 자체를 다시 정해야 한다 — 내가 혼자 정할 것이 아니다).

## 4. V-16 — 낙하 없는 **최소** 힘 (그릇만)

🔔 컵은 E19 로 힘 전환이 없어졌으므로 **그릇만** 한다.

지금 `hold_force_n` 은 35 N 이다. 낮출수록 용기가 덜 상한다. 낙하 0 을 지키는 **가장 낮은 값**을 찾는다.

`src/cobot_common/config/cell.yaml` 의 `presets.BOWL.hold_force_n` 을 바꿔 가며 §3 그릇 순서를 반복:

| 힘 | 낙하 | 폭 변화 | 판정 |
|---|---|---|---|

**합격**: 낙하 **0 / 10** · 전후 폭 변화 **≤ 2 mm**
→ 낙하 0 인 **가장 낮은 값**을 `hold_force_n` 에 넣는다: `______ N`

🚨 `grip_force_n`(20 N)보다 낮게는 내리지 않는다 — HOLD 가 NORMAL 보다 약할 이유가 없다.

## 6. 막혔을 때

| 증상 | 하는 것 |
|---|---|
| 브링업이 조용히 실패 | `killdrcf` 뒤 다시 (포트 12345 잔류) |
| `gripper_joint_state_publisher.py not found` | `chmod +x` (TS-02) |
| 그리퍼가 힘을 못 읽는다 | `release` 를 먼저 부른다 (빈손에서 기준을 잡는다) |
| `목표에 그대로 도달했다` 경고 | **용기가 안 물렸다.** 빈손도 그렇게 보인다 — 다시 대 준다 |
| 로봇 명령이 안 끝난다 | 강제로 죽였으면 **브링업도 다시** (TS-01) |
| 🚨 안전 스위치가 걸렸다 | 그리퍼 수동 분리 → 복구 → **무슨 명령에서 났는지 적는다** |
| 값이 기준을 못 넘는다 | 이 문서에 **그대로 적고** 멈춘다. 기준을 낮추는 것은 내가 정할 일이 아니다 |

🚨 **Ctrl+C** 를 눌러도 그리퍼는 **쥔 채로 남는다**(놓으면 용기가 떨어져서 그렇게 만들었다).
용기를 손으로 받은 뒤 `release` 를 부른다.
