# F2 Virtual 재검증 (E7·E8·E15 반영 뒤) — 시험 기록

| 항목 | 내용 |
|---|---|
| 담당 | 민범진 (F2) |
| 일시 | 2026-09-21 오후 |
| 대상 | `sense.py` weigh · shake · dip · **leftover_loop** (F2-01·F2-02) |
| 모드 | **Virtual** (격리 `LOCALHOST`) · 이동은 진짜 가상 로봇, 무게·파지만 가짜 |
| 도구 | `src/f2_sense_flow/test/rig_f2_virtual.py all -n 3` |
| **결과** | ✅ **검사 24개 전부 통과** (9/20 판은 13개) |

## 1. 왜 다시 했나

9/20 기록은 **결정 E7(안전 높이 폐지) 이전**이라 근거 절반이 무효가 됐다(그 파일 머리말 참고).
그 뒤 **E8(`kind` 인자)·E15(잔반통 HOME 경유)** 까지 들어와 시험대 자체를 고쳐야 했다.

시험대에서 고친 것
- `_goto` 에 `kind` 전달 (E8 — 없으면 진짜 `cell.yaml` 에서 `ValueError`)
- 검사 2개를 "안전 높이 위/아래" → **"티칭 자세 z 에 도착했는가"** (E7 로 원래 뜻이 사라졌다)
- 🆕 **`loop` 모드 추가** — `leftover_loop` 이 시험대에 없었다. E15 로 경로가 바뀐 곳이라 꼭 필요했다
- 가짜 하중을 차례대로 돌려주게 (`leftover_loop` 은 값이 바뀌어야 루프를 돈다)

## 2. 중간에 드러난 것 — 시험용 설정이 낡아 있었다

첫 실행이 바로 죽었다.

```
KeyError: cell.yaml 의 cell.motion.move_timeout_s 가 없거나 비어 있다
```

V-24(비동기 이동 + 폴링)로 **새 설정 키가 생겼는데** 내 Virtual 설정에 없었다.
→ `src/f2_sense_flow/test/config_virtual/cell.yaml` 에 `move_timeout_s: 30` 추가
(황인재의 Virtual 시험 설정 `src/cobot_common/test/config_virtual/cell.yaml` 과 같은 값)

🔔 **다른 사람의 시험용 설정도 같은 상태일 수 있다** — 공용 함수에 키가 늘면 rig 설정도 같이 봐야 한다.

## 3. 측정값

| 동작 | 실측 | 설정 | 비고 |
|---|---|---|---|
| `weigh` | 첫 회 **2.47 s** · 이후 **0.61 s** | — | 첫 회는 시작 자세에서 오는 이동 포함 |
| `shake(WASTE)` 1회(4주기) | **4.46 s** | 2.40 s | |
| └ 한 주기 | **1.099 s** | 0.60 s | 아래 §4 |
| `dip(RINSE)` 1회 | **3.49 s** | 깊이 60 mm · 유지 1.0 s | |
| **`leftover_loop`** (털기 1회 포함) | **14.38 / 11.97 / 12.13 s** | — | HOME 경유 2번 포함 |

도착 정확도 — `WEIGH` Z 425.0 · `WASTE` Z 300.0 · `RINSE` 되올라옴 300.0 → 300.0, 전부 오차 < 1 mm.
`shake` 뒤 J5 복귀오차 **0.00°** × 3회.

## 4. 🔴 V-07 에 반영할 것 — 털기 오버헤드가 **늘었다**

```
설정      한 주기 0.60 s
9/20 실측 0.954 s   (오버헤드 0.354 s)
9/21 실측 1.099 s   (오버헤드 0.499 s)   ← 약 0.15 s 늘었다
```

**V-24 로 이동이 비동기 + 폴링 방식으로 바뀌면서** 명령당 대기가 늘어난 것으로 보인다
(한 주기는 명령 3번 = `period/4` + `period/2` + `period/4`).

🚨 **V-07 에서 `period_s` 를 정할 때 "적은 값보다 주기당 약 0.5 s 느리게 돈다"를 전제로 해야 한다.**
털기는 "얼마나 빠르게 흔드나"가 잔반을 떨어뜨리는 요인이라 무시할 수 없다.
(오버헤드는 명령 횟수에 비례하므로 `cycles` 를 늘려도 주기는 그대로다)

## 5. 용기 1개에 F2 가 쓰는 시간 — 다시 잰 값

9/20 추정(잔반 없음 12 s · 있음 30 s)은 **안전 높이 왕복이 있던 때**의 값이라 다시 잰다.

| 경우 | 9/21 Virtual 기준 |
|---|---|
| 잔반 없음 (`weigh` + `dip` + `shake(RINSE)`) | 약 **9 s** |
| 잔반 있음 (위 + 털기 1회 + 재측정, HOME 경유 2번 포함) | 약 **19 s** |

> 🟡 위는 측정한 조각을 더한 **추정**이다(`leftover_loop` 12 s + `dip` 3.5 s + `shake(RINSE)` ≈ 3.5 s).
> 실기는 `vel_scale 0.3` 이라 더 길어진다. 시연 시간 계산에는 실기 값을 쓴다.

## 6. 이 시험이 **확인하지 못한 것**

| | 여기서 | 실기에서 |
|---|---|---|
| 이동·관절 왕복·Z 하강·**HOME 경유** | ✅ | 재확인 |
| 호출 순서·연속 3회 | ✅ | 재확인 |
| **무게 값·잔반 임계** | ❌ 가짜 | 🔴 V-02 |
| **파지 폭·힘·미끄러짐** | ❌ 가짜 | 🔴 V-01·05·16·23 |
| **충돌 감지 오작동** | ❌ | 🔴 V-07 |
| 잔반통 자세가 **뒤쪽으로 바뀐 뒤**의 실제 경로 | ❌ 가상 좌표다 | 🔴 티칭 뒤 |

🚨 **좌표는 가상 값이다.** E15 의 "앞뒤를 HOME 으로 잇는다"는 **순서**를 확인한 것이지,
실제 잔반통 자세에서 손목이 안 꼬이는지는 티칭 뒤에 다시 본다.
