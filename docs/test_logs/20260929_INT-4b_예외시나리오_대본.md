## 2. 시나리오 카드

### ⓪ 대용품 94 g 무게 확인 (E39 종결 · 9/24 황인재) — 리허설 시작 전 10분
- **왜**: 9/23 98 g 이 50.1~91.4 g 으로 읽혔다(빈 그릇 노이즈 ±25). 시연은 **94 g 1개를 그릇 2·컵 2 중 아무 용기에** 넣고 판정 기준 50 g 그대로 — 그날 저울 상태로 1개가 충분한지 본다.
- **넣는 법**: 기준값 2종을 먼저 잰다(`rig_f2 empty --kind BOWL` · `--kind CUP` · HOME 경유) → 94 g 을 그릇에 넣고 `rig_f2 weigh --kind BOWL` 3회 → 컵도 3회.
- **통과**: 6회 모두 읽음 − 기준값 ≥ **65 g** → 1개 그대로. 하나라도 **60 g 아래** → 2개로(또는 기준 50 → 40 · 황인재 결정). 결과를 §3 표 첫 줄에.

### ⑤ 정지 · 재개 · 중단 버튼 (E11 정리 순서 = 곧게 위로 → HOME → 툴 반납 → 격리 → HOME)
- **배치**: 그릇 1(슬롯 1 · 빈 그릇) · 수세미 홀더 · B1 비움. 시작 → 그릇이 세제(SOAP) 단계에 들어갔을 때(수세미를 든 상태).
- **넣는 법**: ① HMI **일시 정지** → 로봇이 그 자리에서 멈추는지(이동 중이면 바로 · 세제 비틀기(periodic) 중이면 그 구간 끝나고) → 10초 뒤 **재개** → 하던 동작을 이어서. ② 다음 닦기(WIPE) 단계에서 다시 **일시 정지** → **중단**(확인 창 "이 용기를 격리 구역으로 보내고…" → 확인).
- **볼 것**: 정지 로그 `stop 요청 — … 정지` / HMI `일시 정지됨 — 세제 단계` · 재개 로그 `resume — 이어서 진행한다` · 중단 로그 `abort — 이 용기를 접고 다음 용기로 간다` → `중단 정리` 순서: 곧게 위로(safe_retreat) → HOME → **수세미 반납**(툴을 든 채였으므로) → 그릇을 격리 구역(J1 −210 · #90)에 놓기 → HOME → 이벤트 `ISOLATED` → 다음 용기 없음 → `plan 완료 — 그릇 0 · 컵 0 · 격리 1`.
- **통과**: 정지가 5 s 안에 걸림 · 재개 뒤 같은 단계 이어감 · 중단 정리 4단계가 실패 로그 없이 끝나고 수세미가 홀더에, 그릇이 격리 구역에, 로봇 HOME · HMI 이력에 ISOLATED 1줄.
- **실패 시**: 정리 중 한 단계가 실패해도 코드는 계속 치운다(로그 `중단 정리 — … 실패`). 로봇이 이상한 자리에 멈추면 E-Stop → 복구 도구.
- **주의**: 중단은 **PAUSED 에서만** 받는다(먼저 일시 정지). 수조 안에서 중단하면 곧게 올라온 뒤 HOME 으로 간다(9/22 충돌 뒤 규칙).

### ② 빈 구역 → EMPTY_ZONE → SKIPPED → HOME (#98 · 🟡 실기 0회)
- **배치**: 그릇 2(슬롯 1·2) · **컵 구역 두 슬롯 모두 비움** · 팔레트 비움.
- **넣는 법**: 시작. 그릇 2개가 정상 처리된 뒤 컵 구역으로 가서 슬롯 1 빈손(폭 ≈0.4 ✗) → 슬롯 2 빈손 → `EMPTY_ZONE`.
- **볼 것**: 로그 `grip(CUP) … ✗ (빈손·헛잡음)` 2회 → 정책 `next_zone` → 이벤트 **SKIPPED**(kind CUP) → 마지막 구역이 비었으므로 메시지 `반납 구역 확인 완료 — HOME 복귀 중` → HOME → `plan 완료 — 그릇 2 · 컵 0 · 격리 0`. HMI: 컵 슬롯 2개가 빈 표시 · 이력 SKIPPED.
- **통과**: 두 슬롯 확인 뒤 **접근 높이에서 HOME 으로 곧장** 가는 길이 툴 홀더·수조에 안 걸림(🟡 새 경로 · 눈으로) · plan 완료.
- **변형(시간 있으면)**: 그릇 구역만 비우고 컵 2 — 그릇 SKIPPED 뒤 **HOME 을 거치지 않고** 컵 구역으로 가는지(마지막 구역이 아니라 HOME 복귀 없음 · 슬롯 2 접근점 → RET_C 접근점 직선 경로 확인).
- **실패 시**: HOME 복귀 실패면 PAUSED(`EMPTY_ZONE 후 HOME 복귀 실패`) → 사람이 확인 → 재개하면 HOME 재시도.

### ① 잔반 과다 → LEFTOVER_REMAIN → 멈춤(E42 pause) — 그릇 1회 · 컵 1회
- **원리**: 무게 − 기준값 > 50 g 이면 잔반통에서 4회 털고 다시 잰다(최대 2회). 두 번 털어도 50 g 넘게 남으면 `LEFTOVER_REMAIN` → 정책 **pause** → 용기를 **든 채** 무게 자세에서 멈춘다(반납 구역 슬롯 1 위 ≈100 mm).
- **배치**: 대용품 **94 g 1개**(⓪ 에서 2개로 정했으면 2개)를 용기 안에 **테이프로 고정**(털어도 안 나오게 · 두 번 털어도 ≥ 50 g 남아야 LEFTOVER_REMAIN 이 난다) — 고정 없이 넣고 재측정 전에 다시 넣는 방법은 손이 움직이는 로봇 근처에 가서 쓰지 않는다. **시작 직전 기준값 2종**(`rig_f2 empty --kind BOWL/CUP` · HOME 경유)을 다시 잰다 — 9/23 컵 기준값이 15 → 실측 −49.6 으로 틀어졌었다.
- **넣는 법 (a) 덜고 재개**: 멈추면(로그 `PAUSED — resume 을 기다린다 · 코드 LEFTOVER_REMAIN` · HMI `일시 정지됨 — 무게 단계`) → 한석형이 **테이프를 떼고 대용품을 꺼낸다**(로봇 정지 상태 · 그리퍼는 계속 쥔 채) → 황인재 **재개** → 로그 `재개 — WEIGH 단계부터 다시` → HOME 거쳐 무게 자세 → 다시 재기 → 통과 → 놓기부터 정상 진행 → DONE.
- **넣는 법 (b) 중단**: 컵으로 반복하되 멈춘 뒤 **중단** → 정리: 곧게 위로 → HOME → (툴 없음) → 격리 구역(컵 posj · 9/21 경로) → HOME → 이벤트 ISOLATED → 다음 용기.
- **볼 것**: 첫 무게 ≈ +94(1개) → `털기 1/2` → 재측정 여전히 ≥ 50 → `털기 2/2` → 재측정 ≥ 50 → `LEFTOVER_REMAIN` → PAUSED. 잔반 털기가 **스플라인(한 곡선)** 으로 도는지(3차 튜닝). (a) 재개 뒤 재측정 ≤ 50 통과. (b) 격리 경로가 오른콽 홀더·수조 위를 안 지나는지(J1-only #90 은 그릇 실기 완료 · 컵 posj 경로는 9/21 실기).
- **통과**: (a) 멈춤 → 재개 → DONE 기록 1줄 · (b) 멈춤 → 중단 → ISOLATED 1줄 · 두 경우 모두 용기를 **떨어뜨리지 않음**(E42 전에는 다음 집기에서 떨어뜨렸다).
- **실패 시**: 멈춘 채 아무 버튼도 안 먹으면 Ctrl+C → rig_release(용기가 반납 구역 위라 슬롯으로 떨어진다 — 아래 확인) → release_force --home.
- **주의**: 무게는 흐름 경고(`📉 … 흘렀다`)가 잦다 — 판정이 이상하면 기준값 재측정부터. 대용품 2개가 200 g 근처라 그리퍼 20 N 벽 파지가 견디는지 ①에서 함께 본다(9/23 은 98 g 1개까지).

### ③ 툴 놓침 → TOOL_LOST → PAUSED → 홀더에 다시 → 넛지/재개 → 재PICK → 이어가기 (#99 · flow_node 경로 🟡) — **그릇만**
- **원리**: soap/wipe 가 시작할 때 쥔 폭을 기준으로 삼고, 닦는 동안 폭이 1 mm 넘게 바뀌면 즉시 정지(stop_now) → `TOOL_LOST` → 정책 pause. 재개(HMI **재개** 또는 **넛지 = 로봇을 15 N 이상으로 2 s 안에 두 번 톡톡** · E48 · 한 번 꾹 누르는 건 1번으로만 셈) → 코드가 `f1.tool PICK` 을 다시 불러 **홀더에서 다시 집고** 닦기 단계부터 이어간다.
- **배치**: 그릇 1(빈 그릇) · 수세미 홀더 · B1 비움.
- **넣는 법 (안전한 방법)**: 닦기(WIPE) 단계 중 **바닥 나선 구간**(로그 `wipe_bowl 나선` 뒤 · 로봇이 순응 상태로 그릇 바닥에서 천천히 14 mm 원을 돈다)에 박진용이 **옆에서** 수세미 손잡이를 잡고 **위로 당겨 뺀다**. 폭이 바뀌는 순간 로봇이 멈춘다(로그 `나선 도는 중 중단: … 놓침 의심` → `TOOL_LOST` → `PAUSED`). 🚨 세제(SOAP) 비틀기 구간·벽면 회전 구간·빠른 하강 중에는 손 대지 않는다. 🚨 **정지 중에 미리 빼 두는 방법은 안 된다** — wipe 가 시작할 때 폭을 새로 재서 놓침을 못 본다.
- **재개**: 박진용이 수세미를 **홀더에 원래 방향으로** 꽂는다 → 황인재 **재개**(1차 · 확실) / 2차로 **넛지**(손목을 15 N 넘게 **두 번** 톡톡 · 2 s 안)로 재개되는지도 한 번 — 한 번만 치면 재개되지 **않아야** 정상(E48).
- **볼 것**: PAUSED 뒤 HMI 알람 `일시 정지됨 — 닦기 단계` · 재개 로그 → `tool` 재PICK: 그리퍼 열기 → **집었던 자리 위로 직선**(그릇 안에서 빠져나올 때 **그릇 테두리에 손가락이 걸리지 않는지** 🟡) → 홀더 자리로 곧게 내려가 집기(폭 25.6) → 로그 `재개 — WIPE 단계부터 다시` → 닦기 처음부터(하강 → 바닥 → 나선 → 벽) → 반납 → 이어서 DONE. 넛지로 재개했으면 로그 `넛지 감지 — 이어서 진행한다` 와 (#102) 로봇 상태 STANDBY 복귀 대기.
- **통과**: 놓침 뒤 0.5 s 안에 정지 · 재PICK 성공(TOOL_FAIL 아님) · 닦기 완주 · DONE 기록. HMI 에 PAUSED → 진행 복귀.
- **실패 시**: 재PICK 이 헛잡으면 `TOOL_FAIL → retry:1 → isolate` 로 정책이 바뀌어 용기가 격리된다(기록 ISOLATED · 시연 규칙상 통과 아님). 로봇이 그릇 안에서 멈춘 채 오류면 Ctrl+C → release_force --home(빈손) 뒤 수세미는 손으로.
- **컵(솔)은 제외**: 컵 닦기는 손목이 180° 를 계속 돌며 위아래로 움직여 손으로 빼기 위험. 시연에는 그릇 TOOL_LOST 만.

### ④ 케이블 장력 이상 → PAUSED → 톡톡 → 재검증 → 재개 (#93 · #102 · 실기 1회)
- **원리**: 무게를 잴 때 30개 표본의 **떨림(최대−최소)이 80 g(`f2.limits.max_weigh_spread_g` · E47 50→80)** 을 넘으면 `CableTightError` → 그 자리에서 PAUSED(HMI 메시지 `케이블 상태를 확인해주세요. 확인 후 로봇을 가볍게 톡톡 두드려 주세요.`) → 사람이 **톡톡 두 번**(15 N 이상 · 2 s 안 · `f2.nudge.force_threshold_n` 15 + `cell.limits.nudge_taps` 2 · E48) 또는 HMI 재개 → (#102) 로봇이 SAFE_STOP 이면 자동 해제 → 1.5 s 대기 → 10표본 재측정 → 떨림 ≤ 80 이면 `케이블 상태 정상 확인 — 작업 재개` → 무게 단계부터 다시.
- **배치**: 그릇 1(빈) · 나머지 정상.
- **넣는 법**: 로그 `weigh` 표본을 재는 동안(무게 자세 도착 + 8 s 뒤 약 20 s 창) 민범진이 **그리퍼 케이블을 가볍게 흔든다/당긴다**(로봇 팔은 안 만짐) → 떨림 > 80 g → PAUSED. → 손을 뗀 뒤 3 s → 로봇 손목을 **톡톡 두 번**(15 N 넘게 · 2 s 안 · 한 번만 치면 안 재개돼야 정상 · 세게 치지 않기 — 9/23 실기에서 세게 밀어 SAFE_STOP 이 걸린 적 있음 → #102 가 자동 해제) → 재검증 → 재개.
- **볼 것**: `🔗 weigh(BOWL) 케이블 장력 이상 감지: 떨림 N g > 상한 80 g` → PAUSED · HMI 알람 메시지 · 톡톡 뒤 `👉 톡톡(넛지) 감지` → `재개 요청 감지(유형: nudge)` → **HMI 비프 3번**(#93) → (SAFE_STOP 이면 `recover` 로그) → `케이블 상태 정상 확인(떨림 … ≤ 80)` → 무게 다시 → 정상 진행.
- **통과**: PAUSED 진입 · 두 번 치기로 재개(한 번은 무시) · 재개 뒤 무게 정상 · DONE. 톡톡이 안 먹으면 HMI 재개로도 됨(둘 다 확인).
- **실패 시**: 재검증에서 계속 > 50(`케이블 이상 지속`)이면 케이블을 정리하고 다시 톡톡. 로봇이 SAFE_STOP 인데 자동 해제가 안 되면 펜던트.
- **주의**: 9/23 컵 1 무게에서 흔들지 않아도 떨림 45 g 이 나왔다 → E47 로 상한 80. 80 을 넘기려면 케이블을 꽤 흔들어야 한다(당기지는 말 것). 이 시나리오는 "일부러 넘겼을 때 복구되는가" 를 본다.
