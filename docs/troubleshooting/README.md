## 쓰는 법
1. 파일 이름 `TS-번호_짧은제목.md`. 위 표에 한 줄 추가.
2. 항목: 증상(오류 문구 그대로) · 재현 방법 · 원인 · 해결 · 재발 방지 · 확인한 범위와 남은 확인.
3. 재현 스크립트가 있으면 `ts번호_repro/`에 둔다.
4. 규칙으로 굳힐 내용은 `AGENTS.md` §5 환경 함정 또는 SDD에 반영하고 여기서 링크한다.
